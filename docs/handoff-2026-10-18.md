# Handoff 2026-10-18: Open with / Share (0.2.0, tested on the owner's phone)

| Path | Result |
| --- | --- |
| Android lists Noctívago (VIEW + SEND, octet-stream and zip; VIEW by `.ncvpreset` path) | Yes (`cmd package query-activities`) |
| Open with, app closed (adb VIEW, content://media) | Imports, opens the player |
| Open with, app open | Same |
| Share from My Files, app open and app closed | Imports, opens the player |
| Same-name re-import | Replaces the saved copy (one entry, moves to the top) |

Notes:
- adb `am start -a SEND --eu android.intent.extra.STREAM …` fails with "Couldn't read that file": `am` does not attach the read grant for EXTRA_STREAM. Real apps do; test Share through a real share sheet.
- The owner's phone sends unknown files to Material Files by default, so tapping a `.ncvpreset` in My Files skips the chooser. Fix on the phone: Settings → Apps → Material Files → Set as default → Clear defaults.
- Samsung's second profile also has a Noctívago copy (orange badge in the share sheet); the plain icon is the main one.
