# Handoff 2026-10-17: clicks when the screen turns off (resolved in 0.0.4)

Owner test of 0.0.1: clicks the moment the screen turned off.

Measured on the owner's phone over Wi-Fi adb (Android's track underrun counter, `dumpsys media.audio_flinger`, missing frames per second of 48000, screen off = Dozing):

| Build | Reverb | Screen off: frames missing |
| --- | --- | --- |
| 0.0.3 (PowerSaving output only) | On | ~15,300/s (~32%) |
| 0.0.3 | Off | 0 |
| 0.0.4 (convolver inline) | On | 0 over 150 s |

Two causes, both patched in `patches/react-native-audio-api+0.13.6.patch`:
1. `AudioPlayer.cpp`: low-latency exclusive output → Shared + Media/Music + PowerSaving + full buffer (deep-buffer output, ~80 ms).
2. `ConvolverNode.cpp`: each 128-frame quantum handed channels to a 4-thread pool and waited; Android throttles those threads when dozing. Now inline on the audio thread.
