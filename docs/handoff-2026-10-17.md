# Handoff 2026-10-17: clicks when the screen turns off

Owner test of build b0a902e9 (spike v0.0.1): clicks and noise start the moment the screen turns off.

Cause (from the library source): `react-native-audio-api` 0.13.6 opens the Android output with Oboe `SharingMode::Exclusive` + `PerformanceMode::LowLatency` + 128-frame callbacks (`android/src/main/cpp/audioapi/android/core/AudioPlayer.cpp`). Screen off → CPU slows → the 2.7 ms deadlines (convolver included) underrun.

Done (uncommitted, only inside node_modules, so a reinstall wipes it):
- `AudioPlayer.cpp` `openAudioStream()`: Shared + `Usage::Media` + `ContentType::Music` + `PerformanceMode::PowerSaving`; after open, `setBufferSizeInFrames(getBufferCapacityInFrames())`.

2. `npm i -D patch-package`, add `"postinstall": "patch-package"`, run `npx patch-package react-native-audio-api` → `patches/` file. Commit.
